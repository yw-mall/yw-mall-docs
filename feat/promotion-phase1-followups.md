## 项规范

新增一条时填以下信息:
- **#**: 序号递增
- **发现日**: YYYY-MM-DD
- **模块**: 影响的具体子模块 (C 端购物车 / 商家活动 FE / 价格引擎 / ...)
- **描述**: 一句话讲清现状 + 期望; 复杂的链 PR/issue
- **估算**: 人天 (用 stories 文档同一标准)
- **优先级**: 🔴 高 (UX 严重错位 / 数据正确性) / 🟡 中 (体验差但非致命) / 🟢 低 (锦上添花)
- **状态**: TODO / IN_PROGRESS / DONE ✅
- **责任**: 谁负责跟进 (未指派填 -)

关闭时:
- 状态改 DONE ✅
- 在 "已关闭" 表下追加一条, 带 commit hash + 关闭日期
- 不要删除原行 (保留历史)
