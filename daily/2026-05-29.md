### go.work — IDE 长期标红问题

**问题**：yw-mall 仓库下 16 个独立 Go module + yw-mall-admin 独立 module = 17 个 go.mod。每个 module 用 `replace ... => ../mall-common` 等指令做跨 module import，但**这只对 `go build` 生效，gopls 不读 replace**。

整个 session 的 IDE diagnostic 一直在提示：
```
This file is within module "../yw-mall-admin", which is not included in your workspace.
To fix this problem, you can add a go.work file that uses this directory.
```

**修法**：mall/ 根目录加 `go.work`（不入任何子仓库，纯本机 dev 配置）：

```
go 1.26.1
use (
    ./yw-mall-admin
    ./yw-mall/mall-api
    ./yw-mall/mall-common
    ... (共 17 个 module)
)
```

跑了 `go work sync` 验证 + build 正常。

**生效条件**：重启 gopls（VSCode/Cursor: `Cmd+Shift+P → Go: Restart Language Server`）。
