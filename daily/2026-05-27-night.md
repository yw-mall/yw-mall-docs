## 🔧 主要交付

### 后端 (M2 T1-T6)

**数据表（mall-product-rpc/sql/sku.sql）**
```
sku (id, product_id, shop_id, sku_code, spec_text, spec_json,
     price, stock, image, status, create_time, update_time)
- UNIQUE(product_id, sku_code) 防同 SPU 重复
- KEY(product_id, status) 详情主索引
- KEY(shop_id, status) 按店扫备用
- status 0/1 软删
```
**关键设计**：product 表保留 price/stock/images 作 default SKU 聚合视图，C 端列表/搜索路径**完全不读 sku 表**，零改造。

**一次性回填脚本（cmd/backfill_default_sku）**
40 个历史 product 全部生成 default SKU（sku_code=P{pid}-S1），幂等可重跑。

**Proto + RPC 8 个新增/扩展**：
- `SkuInput` / `SkuItem` / `BatchUpsertSkusReq` / `BatchUpsertSkusResp`
- `CreateProductReq` 加 `skus[]` + `brand` + `detail` 字段
- `ProductDetailResp` 加 `skus[]` 字段
- 新 RPC `BatchUpsertSkus(product_id, shop_id, skus[])`

**product-rpc logic 改造**：
- `skuhelpers.go`：`upsertSkusAtomic` 单事务 INSERT/UPDATE 支持软删；`listSkusByProduct` 给详情用；`syncProductAggregateInTx` 按 MIN(price)/SUM(stock) 聚合回写
- `BatchUpsertSkusLogic`：校验 product 归属 shopId 防越权 + 单事务保证 SKU upsert + 聚合原子性
- `createproductlogic` 改造：`in.Skus` 空走 default SKU 兼容路径，非空走数组 + 聚合；raw SQL UPDATE 补 brand/detail（model.Product 没这俩字段）
- `getproductdetaillogic`：拼上 active skus 列表

**admin-api 图片上传**：
- `Minio` 配置块（optional），svc 引 `mall-common/minioutil`
- `POST /merchant/v1/upload/image`：multipart 6MB form size，5MB 文件 + jpg/jpeg/png/webp 白名单，按 `product-images/shop-{id}/{ts}.{ext}` 分目录
- 走 `mall-common/minioutil.Client.PutFile`，返 (url, key)

**admin-api SKU 透传**：
- `MerchantCreateProductReq` 加 `Skus[]` + `Brand` + `Detail`，optional 标记
- `MerchantBatchUpsertSkus` 需 `product.write` perm，透传到 product-rpc
- `POST /merchant/v1/products/:id/skus`
- `ProductDetail` DTO 加 Skus 字段，`MerchantGetProduct` map 透传

### 前端 (M2 T7-T9)

**API 层**：
- `api/products.ts`：CRUD + setStatus + setStock + batchUpsertSkus，unwrap 兼容 ApiResponse 双 shape
- `api/upload.ts`：axios 直调 `POST /merchant/v1/upload/image`，FormData 避开 request.ts JSON 拦截

**通用组件**：
- `ImageUploader.vue`：el-upload 包装，5MB+jpg/png/webp 白名单，调 uploadImage → push 进 modelValue 数组
- `SkuMatrix.vue` **核心**：属性组多值 → 笛卡尔积生成 SKU 列表；保留已有 SKU 的 price/stock（按 specText 匹配，重新生成不丢数据）；「无规格（单 SKU）」一键模式

**页面**：
- `views/product/list.vue`：状态筛选 + 缩略图 + 价格分→元 + **库存 inline 编辑** + 上下架 toggle + 分页
- `views/product/edit.vue`：SPU 表单 + ImageUploader 多图 + SkuMatrix；onMounted 预填编辑；保存：新建调 createProduct(含 skus)，编辑分两步 updateProduct + batchUpsertSkus

**路由 + 菜单**：
- 加 `/products` + `/new` + `/:id/edit`，meta.perms 守卫

## 🐛 排错记录

| 现象 | 根因 | 修法 |
|---|---|---|
| createProduct 报 "field price is not set" | go-zero `httpx.Parse` 不识别 `json:"price,omitempty"`，要 `optional` tag | 把 MerchantCreateProductReq 大部分字段改 `optional` |
| start.sh restart 没真重启 | sleep 2 太短 + cwd 切走 | 明确从 yw-mall 根目录跑 + sleep 3 |
| go build 报 "updates to go.mod needed" | admin-api 第一次引 minio-go | `go mod tidy` |
| detail 返回没 skus 字段 | admin-api 的 ProductDetail DTO + map 都没接 skus | 加 Skus 字段 + 在 MerchantGetProduct map skus 数组 |
| Product model 没 brand/detail 字段 | goctl 生成的 model 滞后于 DDL | raw SQL `UPDATE product SET brand=?, detail=?` 在 createproduct 末尾补 |
