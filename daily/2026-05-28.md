### 6 个 dev workflow 排坑

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 商家编辑商品 PUT 400 `field "price" is not set` | `MerchantUpdateProductReq` `json:"price"` 缺 `optional` tag，go-zero 不识别 `omitempty` | 全字段加 `optional` (commit `f9a3596`) |
| 2 | C 端 login 500 | yw-mall-fe vite proxy `/api → :9080` (APISIX)，但 APISIX 容器从 podman bridge 段访问宿主 :18888 被 firewall 拦 | vite proxy 直连 :18888 (commit `69d8d25`) |
| 3 | APISIX upstream 解析失败 | upstream nodes 写死容器名 `yw-mall-deploy_mall-api_1`，dev 模式宿主跑业务无法解析 | setup.sh 加 env 变量覆盖（prod 默认容器名 / dev override host.containers.internal）(env commit `90e5e4e`) |
| 4 | mall-api 周期性 etcd1 解析失败 → 服务调不通 | etcd 容器 advertise-client-urls 公告容器名 `etcd1:2379`，etcd client cluster sync 后用 `etcd1` 重连解析失败 | 宿主 `/etc/hosts` 加 `127.0.0.1 etcd1`（dev hack，不入仓库）|
| 5 | C 端商品列表图片不显示 (URL 拼成 comma-csv) | 后端 `product.images` 是 csv 字符串，FE 类型声明 `string[]`，view 用 `images[0]` 拿到 `"h"` | api 边界 normalize string → array (commit `5fa82d9`) |
| 6 | SkuMatrix 输入框看着能聚焦但不能编辑 | `el-input :model-value` + `@change` 只在 blur 触发，期间 `:model-value` 反复覆盖 keystroke | 改 `@update:model-value` 立即同步 (commit `3708eb9`) |
| 7 | `GET /merchant/v1/freight-templates` 500 | `first_value` 是 MySQL 8+ 窗口函数保留字 | SELECT/INSERT 加反引号 (commit `7b8e963`) |
